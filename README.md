# PayBox SIT Innovation Lab (English version)

An interactive explorer of 2,000 product ideas for PayBox (payboxapp.com), generated with the five Systematic Inventive Thinking (SIT) templates: Subtraction, Multiplication, Division, Task Unification and Attribute Dependency. Each idea has a FORM and a FUNCTION. A zoomable scatterplot places every idea by originality (X, from FORM) and usefulness (Y, from FUNCTION). You can filter by template, search semantically by desired use, and export the ideas as CSV or JSON.

**Live site:** https://mosesmiller.github.io/paybox-sit-innovation-lab-en/

This is the English-only version. The original version is at https://mosesmiller.github.io/paybox-sit-innovation-lab/

The site is a single self-contained `index.html`. It loads Tailwind and Google Fonts from the web, so it needs an internet connection to look right.
